### **Steps to implement**

#### **1\. Add UI-only phase state**

In client/src/pages/findings.tsx, introduce a UI-only state:

```
type AuditPhase =
  | "profile"
  | "rules"
  | "classification"
  | "mapping"
  | "done"

const [auditPhase, setAuditPhase] = useState<AuditPhase>("profile")
```

This state controls **visibility only**, not computation.

* * * * *

#### **2\. Advance phases progressively after findings exist**

Still compute findings immediately as you do today.

After findings are set, add a useEffect:

```
useEffect(() => {
  if (!findings) return

  setAuditPhase("profile")

  const timers = [
    setTimeout(() => setAuditPhase("rules"), 400),
    setTimeout(() => setAuditPhase("classification"), 800),
    setTimeout(() => setAuditPhase("mapping"), 1200),
    setTimeout(() => setAuditPhase("done"), 1600),
  ]

  return () => timers.forEach(clearTimeout)
}, [findings])
```

These delays are **presentation-only**.

* * * * *
